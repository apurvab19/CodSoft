# Quiz App with Firebase Integration 🎉
A web-based application that allows users to create quizzes, take quizzes, and authenticate seamlessly. Built with Firebase for database and authentication, and Node.js for backend management.
__________________________________________________________________________________________________________________________________________________________________________________________________
Features ✨<br>
🔑 User Authentication: Secure login and registration.<br>
📝 Quiz Creation: Add quizzes with custom questions and answers.<br>
🎯 Quiz Taking: Interactive UI to attempt quizzes with score tracking.<br>
📊 Dynamic Quiz List: Automatically displays available quizzes for users.<br>
__________________________________________________________________________________________________________________________________________________________________________________________________
Technologies Used 🛠️<br>
Frontend:
  HTML, CSS, JavaScript<br>
Backend:
  Node.js (with Express.js)<br>
Database & Authentication:
  Firebase
